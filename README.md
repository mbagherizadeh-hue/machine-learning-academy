# Machine Learning Academy

آموزش تعاملی یادگیری ماشین — فارسی و راست‌چین، مناسب تدریس زنده با ویدئوپروژکتور.

## معرفی
وب‌سایتی آموزشی که جایگزین اسلایدهای پاورپوینت می‌شود. در حال حاضر فقط مبحث **Logistic Regression** پیاده‌سازی شده و سایر مباحث با برچسب «به‌زودی» نمایش داده می‌شوند.

## امکانات
- ۱۲ درس Logistic Regression به‌علاوه درس کد Python، آزمون و منابع
- ۵ آزمایشگاه تعاملی: Sigmoid، Threshold، Log Loss، Gradient Descent، Decision Boundary
- حالت کلاس (Presentation Mode): دکمه یا کلید `P`؛ حرکت بین درس‌ها با کلیدهای جهت‌دار
- نوار پیشرفت که در LocalStorage مرورگر ذخیره می‌شود
- بدون API پولی، بدون کلید و بدون بک‌اند

## فناوری‌ها
HTML + CSS + JavaScript خالص در یک فایل (`index.html`)، فونت Vazirmatn از Google Fonts، نمودارها با SVG. مرحله Build وجود ندارد.

## اجرای محلی
گزینه ۱: فایل `index.html` را مستقیم در مرورگر باز کنید.

گزینه ۲ (نیازمند Node.js):
```bash
npm start
```
سپس آدرس http://localhost:3000 را باز کنید.

## انتشار
مخزن را به Vercel وصل کنید (Framework Preset: Other، بدون Build Command، Output Directory: `.`). هر Push روی شاخه `main` به‌صورت خودکار منتشر می‌شود.

## یادداشت علمی
مثال‌های عددی و داده‌های دیتاست قبولی دانشجویان فرضی‌اند. پیش از تدریس، محتوا را با فصل ۴ کتاب Géron (ویرایش سوم) و لینک‌های بخش منابع مطابقت دهید.
